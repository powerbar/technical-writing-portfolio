# Hsiu-Hsien Chen — Technical Writing Portfolio

Ready to publish with GitHub Pages.

## Recommended repository name
`technical-writing-portfolio`

## Publish
1. Create a new public GitHub repository named `technical-writing-portfolio`.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. The site should appear at:
   `https://powerbar.github.io/technical-writing-portfolio/`

Use that URL in the AUQ Portfolio field.

If you later want a permanent root portfolio at `https://powerbar.github.io/`, we can convert this into the special `powerbar.github.io` repository.
